# Project rules

- Keep the quiz self-contained in `index.html`; do not add dependencies or require a server.
- Use semantic, keyboard-accessible HTML and keep the layout responsive and centered in a narrow column.
- Preserve light/dark color-scheme support and reduced-motion preferences when changing styles.
- Keep question data, scoring, progress, feedback, and results behavior consistent when editing the quiz.
- Verify UI changes by opening `index.html` in the integrated browser and exercising the affected flow.
